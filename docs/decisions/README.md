# 决策记录

本目录记录会长期影响产品或技术实现的关键决策，避免重要背景只存在于聊天记录中。

仅记录真正需要保留理由的决策，例如：

- 小程序技术栈与后端技术栈
- 大模型供应商和降级策略
- 角色包及输出协议的版本方式
- 用户文件保留与删除策略
- 自定义暴君的编译和安全边界

文件命名建议：

```text
YYYY-MM-DD-short-decision-title.md
```

每份记录至少说明：背景、决定、理由、替代方案和影响。
