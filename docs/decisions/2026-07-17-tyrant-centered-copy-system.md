# 统一为“暴君治下验收”的文案世界观

> 状态：已由 [2026-07-22：公开语气改为尖酸刻薄的直属领导](2026-07-22-sharp-manager-copy-voice.md) 调整。继续保留本记录，用于说明为何禁止混用暴力、追债和验尸隐喻。

## 背景

当前界面同时使用刀、追债、判死、验尸等多套隐喻。它们能制造刺激，却让四个角色像由模板随机拼接，也削弱了用户“正在暴君面前交工作”的代入感。多角色扩展后，共用差材料模板还会把汇报、文案和产品问题说成同一种话。

## 决定

1. 公开角色统一使用“XX 暴君”命名。
2. 用户体验统一描述为：呈上材料、暴君过目、逐条点名、下达批示、对照验收线，最后判为当场打回、尚未过关或准予交付。
3. 公开界面和模型输出不再混用刀、砍、刀口、追债、欠债、判死、死罪、验尸等隐喻。
4. `critical` 报告固定使用 1-2 处证据绑定的作品级狠词，例如“屁话、垃圾材料、垃圾写法、废物话术、废纸”；只能修饰材料、写法或表达，禁止智力和人格侮辱。`rebuilding` 最多 1 处带刺提醒，`ready` 不强塞辱骂。成熟材料必须明确认可并说明准予保留的理由。
5. 四个角色分别使用自己的专业语言和样例报告，不以一个通用差材料模板代替角色判断。
6. 内部 role ID、schemaName 和 API 合约保持稳定；旧 ID 不代表公开文案仍沿用旧隐喻。

## 词汇边界

- 推荐：呈上、过目、点名、批示、验收、打回、过关、准予保留、准予交付；差材料可在证据命中处使用屁话、垃圾材料、垃圾写法、废物话术、废纸。
- 避免：刀、砍、刀口、追债、欠债、判死、死罪、验尸，以及与角色专业无关的泛化辱骂。

## 结果

首页、角色详情、提交、处理、报告、分享和真实 AI 生成使用同一情绪母题。未来新增角色也以专业领域区分能力，不再依靠更换暴力隐喻制造差异。
